# 書き出してみる

おつかれさまです。マキナです。

ここまで来たなら、

- Shelfから引用を探す
- 引用を文章へ入れる
- Markdownを書く
- 画像をProjectへ入れる
- draftをSynced Blockでbodyへ組み込む

ところまでできています。

最後に、このProjectの外でも読めるファイルを作ってみましょう。

## 1. sample-bを開く

`sample-b_小さなレポート.md` を開いてください。

Previewに切り替えて、

- 見出し
- 本文
- `sample-c`から同期された文章
- 挿入した宮沢賢治の写真
- 引用
- 参考文献

が意図した状態になっているか確認します。

Shelfパネルの `Refresh References` を実行し、sample-cから同期された引用も含めて参考文献が解決されていることを確認します。

## 2. Markdownを書き出す

Command Paletteから `Export Markdown` を実行してください。

保存場所はWindowsの「ダウンロード」フォルダ。

ファイル名:

`MAGINALIA_チュートリアル_小さなレポート.md`

Synced Blockは解決され、Project内部の構成をひとつの線形な文章として持ち出せます。

## 3. PDFを書き出す

`sample-b_小さなレポート.md` を対象に `Export PDF` を実行します。

保存先は「ダウンロード」。

ファイル名:

`MAGINALIA_チュートリアル_小さなレポート.pdf`

必要なら書き出し前に用紙や向きを確認します。

## 4. DOCXを書き出す

最後に `Export DOCX` を実行します。

保存先は「ダウンロード」。

ファイル名:

`MAGINALIA_チュートリアル_小さなレポート.docx`

これでWordや対応する文書ソフトでも扱えるファイルができます。

## 5. ダウンロードフォルダを見る

次の4ファイルが見えれば成功です。

- `MAGINALIA_チュートリアル_宮沢賢治.jpg`
- `MAGINALIA_チュートリアル_小さなレポート.md`
- `MAGINALIA_チュートリアル_小さなレポート.pdf`
- `MAGINALIA_チュートリアル_小さなレポート.docx`

3つの成果物をMAGINALIAの外から開いてみてください。

## ここまでできたら

これで一周です。

あなたはもう、

1. Projectを開く
2. Markdownを書く
3. Shelfから資料を探す
4. 引用を使う
5. 画像を入れる
6. 複数の文書を組み合わせる
7. 完成した文章を書き出す

ところまでやりました。

MAGINALIAの中だけで完結する必要はありません。

Markdownとして残してもいいし、PDFにして提出してもいいし、DOCXにして別のソフトで続きを直しても大丈夫です。

元になったProjectと資料は、そのまま残っています。

完成したファイルと、そこへ至るまでに考えたものを、別々に持っておけるわけです。

これでチュートリアルはおしまいです。

ここから先は、あなたの机です。

読んで、残して、考えて、つないで、必要になったら外へ持っていってください。

それじゃあ、いってらっしゃい。
