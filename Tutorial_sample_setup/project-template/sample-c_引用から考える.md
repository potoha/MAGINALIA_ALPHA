# 引用から考える

## 記録すること

私は、文章を読むときに「覚えておこう」と思って、そのまま忘れることがよくある。

だから、面白いと思った言葉は、考えがまとまる前でもいったん残しておく。

<!-- maginalia:quote-ref v1 {"quoteId":"ann:01JABCDEFGHJKMNPQRSTVWXYZ0","mode":"normal"} -->

宮沢賢治は、自分自身を固定した一点ではなく、風景や他者とともに明滅する「現象」として書いている。

読む側の私も、読んだ言葉をただ保存するだけではなく、その時々で別の関係を見つけていくのかもしれない。

## 読むことは技術なのか

<!-- maginalia:quote-ref v1 {"quoteId":"ann:01JABCDEFGHJKMNPQRSTVWXYZ2","mode":"normal"} -->

「読書は一種の技術である」と考えるなら、読むことは才能の有無だけで決まらない。

引用を残すこと。
気になった理由を書くこと。
別の文章とつなぐこと。

そうした小さな操作も、読むための技術の一部として考えられる。

## さいわいについて考える

ここでShelf Searchから「さいわい」を検索して、
『銀河鉄道の夜』の引用をひとつ挿入してみる。

挿入したら、その言葉について一文だけ自分の考えを書いてみる。

完璧な答えでなくていい。
問いを残すだけでもいい。
