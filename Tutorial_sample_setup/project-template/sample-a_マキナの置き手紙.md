# マキナの置き手紙

こんにちは。マキナです。

これを読めているなら、MAGINALIAの準備はちゃんとできています。
机も、本棚も、あなたのためのProjectもあります。

このProjectは、私がちょっとだけ先に触っておきました。

完成品ではありません。
途中まで考えて、途中まで書いて、途中までつないであります。

研究とかレポートって、たぶん最初から完成した文章を書くものじゃないんです。

読む。
残す。
考える。
つなぐ。
そして、書く。

私は、その順番を試せるようにしておきました。

## まず、3つのファイルがあります

- `sample-a` は、いま読んでいる私のメモ。
- `sample-b` は、最後にひとつの文章になる本文。
- `sample-c` は、その本文をつくるための下書きです。

まず `sample-c_引用から考える.md` を開いてみてください。

## Shelfを使ってみる

右側のShelf Searchで `さいわい` と検索してください。

『銀河鉄道の夜』から、ひとつ短い引用が見つかるはずです。

それを `sample-c` の「さいわいについて考える」のところへ挿入してみてください。

引用そのものだけでなく、誰が、どの本に書いたものなのかも一緒にたどれるようになります。

だから、あとで「これ、どこで読んだんだっけ」と記憶力と勝負しなくて大丈夫です。

## 写真も置いてみましょう

Windowsの「ダウンロード」フォルダに
`MAGINALIA_チュートリアル_宮沢賢治.jpg`
という写真を置いてあります。

それを `sample-c` の「画像を置いてみる」の下へドラッグしてください。

MAGINALIAは元画像を勝手に壊さず、Projectで使うための画像をProject側へ取り込みます。

## そして sample-b を見てください

`sample-b_小さなレポート.md` には、`sample-c` が Synced Blockとして入っています。

同じ文章を二回コピーしてあるわけではありません。
`sample-c` を直すと、`sample-b` に入っている内容も変わります。

下書きは下書きのまま。
本文は、その下書きをつないでできていく。

私はこの仕組み、けっこう好きです。

ちゃんと反映されていたら、次は
`sample-d_書き出してみる.md`
を開いてください。

MAGINALIAの中で文章を作るところから、MarkdownやPDF、Word文書として外へ持ち出すところまでやってみましょう。

そこまでできたら、このProjectで私が用意したチュートリアルはおしまいです。

あとはあなたの机です。

好きなものを読んで、気になった言葉を残して、そこから何か考えてみてください。

私が置いていったものが、その最初の一歩くらいにはなれば嬉しいです。

― マキナ
