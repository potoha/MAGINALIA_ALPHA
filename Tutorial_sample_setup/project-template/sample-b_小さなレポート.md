# 読むことを、残して、つなぐ

文章を書く前には、たくさんの途中がある。

読んだこと。
気になった言葉。
まだ名前のない考え。
うまく説明できない疑問。

完成した文章だけを残そうとすると、それらは簡単に消えてしまう。

だから私は、まず材料を残して、それから少しずつ関係を作ることにした。

## おわりに

読むことと書くことのあいだには、考えている途中の時間がある。

MAGINALIAは、その途中を捨てずに扱うための机だ。

引用も、メモも、下書きも、それだけでは完成した文章ではない。

けれど、それぞれを残し、あとからつなぎ直せるなら、
「まだ文章になっていないもの」も研究や創作の一部として扱える。

この文章も、その途中からできている。
